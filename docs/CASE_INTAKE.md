## Вопросы, которые нужно разрешить первыми

1. Как оценивают агента: по качеству построенных ML-моделей, выполнению этапов процесса, качеству сгенерированного кода или совокупности критериев? Есть ли тестовые задания и эталонный формат результата?
2. Какие данные доступны? Как устроено контрольное разбиение и что запрещено использовать при подборе решения?
3. Какие внешние модели, API и библиотеки допустимы? Разрешена ли передача содержимого данных внешнему сервису?
4. Где будет запускаться решение: есть ли интернет, GPU, ограничения памяти, времени и стоимости? Нужен ли полностью автономный запуск?
5. Какие части обязательны для онлайн-этапа, что сдаём и до какого точного времени? Есть ли формальная шкала оценки?

Ответы сохраняем с датой и источником. Вопрос, ещё не отправленный организаторам, не помечаем как согласованный.

## Контракт первого baseline

Заполняем после чтения ТЗ, до расширения реализации:

- **Один демонстрационный сценарий:** не определён.
- **Входы и ожидаемые выходы:** не определены.
- **Простейший допустимый подход:** не выбран.
- **Основная метрика и процедура оценки:** не определены.
- **Разбиение и защита от утечки данных:** не определены.
- **Бюджет одного запуска:** не определён.
- **Выбранный провайдер и основание выбора:** не определены.
- **Команда запуска в чистом окружении:** будет уточнена под кейс.
- **Условие приёмки:** другой участник воспроизводит сценарий, получает валидный результат и может проверить расчёт метрики.
