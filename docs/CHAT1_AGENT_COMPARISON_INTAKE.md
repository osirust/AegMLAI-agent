Не подменяют существующий RESEARCH_PROTOCOL. Полный A/B по две задачи × два seed × два варианта × три часа занимает до 24 машиночасов: это оценка стоимости, не разрешение автоматически запускать такую серию. До неё нужны дешёвые проверки механики.

Три вопроса сохранены для соответствующих этапов: физическая OS-изоляция и train-only преобразования H05; точный development/best-ready/frozen fallback H03/H07; независимый аудит переносимости вместо подбора на двух public H09/H11. Bootstrap H02.2 их не закрывает.
