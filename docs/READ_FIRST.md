# Локальный запуск AegML

Основная точка входа — `solution.py`. Опубликованная версия обучает базовую модель CatBoost для табличной регрессии или классификации.

## Подготовка

Используйте Linux и Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

`task.md` и CSV-файлы должны соответствовать формату задач трека. В описании указываются пути к данным, целевой столбец, метрика и формат прогноза. Также используются словарь признаков и пример файла ответа.

## Выполнение

Перейдите в каталог задачи и запустите код из репозитория:

```bash
cd /path/to/task
/path/to/AegMLAI-agent/.venv/bin/python /path/to/AegMLAI-agent/solution.py task.md
```

Пути в примере замените на свои. Рабочий каталог важен: в нём создаётся `submission.csv`.

В среде конкурса код решения находится рядом с описанием задачи, поэтому команда короче:

```bash
python3 solution.py task.md
```

После выполнения агент выводит отчёт в JSON: статус, метрику и сведения о созданном файле прогнозов. Ошибки формата данных также отражаются в отчёте.

## Как читать код

1. `solution.py` — порядок запуска и обработка ошибок.
2. `aegml_input.py`, `aegml_contracts.py` — описание задачи и входные файлы.
3. `aegml_preprocessing.py` — подготовка признаков.
4. `aegml_baseline.py`, `aegml_estimators.py` — обучение.
5. `aegml_metrics.py`, `aegml_validation.py` — оценка результата.
6. `aegml_submission.py` — выходной CSV.
