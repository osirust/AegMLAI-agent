## Обязательный платформенный формат

Полученный TXT задаёт точную команду `python3 solution.py task.md`; cwd и `submission.csv` — каталог задачи.
В ZIP только root `.py` + неизменённый предоставленный `requirements.txt`, без каталогов; предел 100 МБ, консервативно **`100000000` байт**.
P0 использует `solution.py` и `aegml_*.py`, включая `aegml_schemas.py` / `aegml_prompts.py`. JSON/config/prompt assets, данные и сторонние пакеты/wheels не загружаются.
Платформа устанавливает зависимости из предоставленного requirements. Наш runtime не вызывает pip; локальный subset не становится submission requirements. Исходный список 37 pins не перезаписывается.
Во время исполнения разрешены cwd/подкаталоги/`/tmp`; запрет папок относится к ZIP.

Очередь Boosters не означает завершение. Сообщение «Точность вычисления: …» — признак успешной оценки; подробные логи доступны администраторам. Метка «Лучшее решение», нулевой score и длительность загрузки сами по себе не доказывают API/tools/runtime успех.

## Независимые версии и ресурсы

Четыре участника готовят четыре независимые версии, затем сравнивают их. Этот чат — Владимир/Codex; первые три дня прежнее распределение общих модулей не действует.
Владелец отдельно разрешил research/read/send в чате Vovan; root отправил туда prompt без раскрытия данных. Упомянутый там i5 — чужое или устаревшее сведение, не характеристика нашего ПК с Ryzen 5 9600X.
Сначала регрессия, затем классификация через общий контракт. Три роли одной Qwen предусмотрены; независимые контексты выбираются по сравнению, а не по числу участников.

WSL на E: создана. WSL 24 GiB / Docker 20 GiB / 8 CPU — неприменённый план, сейчас caps не меняются. Платформа задаёт 8 CPU / 32 GB и Python 3.12. Отдельный локальный GPU-эксперимент не заменяет CPU-приёмку.
Выбран provided Qwen API. Другие модели через собственные API запрещены; допустимость локальной той же Qwen UNKNOWN, веса сейчас не скачиваются. ML использует только данные кейса без pretrained-весов. Бюджет 600 ₽ не включён в рабочее планирование.
