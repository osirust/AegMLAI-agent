Нормативные требования — [ТЗ](TECHNICAL_SPEC.md), 50 малых заданий — [WORK_BLOCKS](WORK_BLOCKS.md). Цели: AutoResearch, перенос на новые задачи, качество RMSE/F1 и корректный ответ до трёх часов. Mini — историческая проверка, не текущий продукт.

H02.4: 6/6 ресурсных canary, импорты 13 прямых pins / 45 distributions / Python 3.12.3 и literal Docker CLI двух actual public-задач; [квитанция](H024_RECEIPT.md). Текущий TaskContract прошёл43/108/6, bootstrap24/51/37; [H02_REVIEW_REPAIRS](H02_REVIEW_REPAIRS.md). Прежние34/76 и38/93, а также H022-квитанции сохранены историческими. CLI пока создаёт только два JSON с contract_valid=true и exit 3 / implementation_incomplete, не новый CSV.
Весь H03.1–H03.5 разрешён отдельной командой21.10. После его приёмки следующий H04 выполняется только по новой команде. ML-venv, старая stdlib-venv и история сохраняются; все 74 основных + 17 пересекающихся будущих сценариев остаются NOT_RUN.
H06.1 возможен offline; API-запросов 0, **LIVE_API_ON_OWNER_COMMAND_ONLY**. H06.2 после отдельной команды проверит безопасный tool отдельно от ML. Полные серии на 24/30/72/90 часов — арифметика будущей работы, не обещанная длительность проекта и не автоматически разрешённые запуски.

## Обязательный платформенный формат

Полученный TXT задаёт точную команду `python3 solution.py task.md`; cwd и `submission.csv` — каталог задачи.
В ZIP только root `.py` + неизменённый предоставленный `requirements.txt`, без каталогов; предел 100 МБ, консервативно **`100000000` байт**.
P0 использует `solution.py` и `aegml_*.py`, включая `aegml_schemas.py` / `aegml_prompts.py`. JSON/config/prompt assets, данные и сторонние пакеты/wheels не загружаются.
Платформа устанавливает зависимости из предоставленного requirements. Наш runtime не вызывает pip; локальный subset не становится submission requirements. Исходный список 37 pins не перезаписывается.
Во время исполнения разрешены cwd/подкаталоги/`/tmp`; запрет папок относится к ZIP.

Очередь Boosters не означает завершение. Сообщение «Точность вычисления: …» — признак успешной оценки; подробные логи доступны администраторам. Метка «Лучшее решение», нулевой score и длительность загрузки сами по себе не доказывают API/tools/runtime успех.

## Независимые версии и ресурсы

Четыре участника готовят четыре независимые версии, затем сравнивают их. Этот чат — Владимир/Codex; первые три дня прежнее распределение общих модулей не действует.
Владелец отдельно разрешил research/read/send в чате Vovan; root отправил туда prompt без раскрытия данных. Упомянутый там i5 — чужое или устаревшее сведение, не характеристика нашего ПК с Ryzen 5 9600X.
Для обоих пользовательских чатов Vovan выбран целевой GPT‑5.6 Pro; фактический выбор модели пока не подтверждён из-за UI-проблем. CPU ML ответ чата «1» и статический H02.3 review чата «2» уже разобраны, три замечания парсера закрыты в [H023_REVIEW_FIXES](H023_REVIEW_FIXES.md). Первая попытка H02.4 в чат «1» вернула TooManyRequests; позднее сообщения в1 (исследование H05) и2 (прошлые parser fixes и отдельный полный Docker packet) успешно приняты после уведомления владельца. Ответы на новые пакеты ещё не прочитаны; UI-подтверждение модели остаётся pending; читать по сигналу владельца, без polling, перед каждой отправкой уведомлять. Повтор при необходимости разрешён; причина UI-сбоев без доказательств не устанавливается.
Сначала регрессия, затем классификация через общий контракт. Три роли одной Qwen предусмотрены; независимые контексты выбираются по сравнению, а не по числу участников.

WSL на E: настроена на 24 GiB / swap 4 GiB, фактически видны 25 202 294 784 байт RAM (около 23,47 GiB) и 12 CPU. Локальный контейнер — 20 GiB / no-swap / quota 8 CPU / pids 256; [профиль](container-profile.json). Это более тесная память, чем 32 GB платформы. Default Ubuntu/AEGYX не запускали и их файлы не меняли, но общий WSL memory/swap envelope будущих запусков изменился. H02.4 не является готовностью H05 или GPU-приёмкой.
Выбран provided Qwen API. Другие модели через собственные API запрещены; допустимость локальной той же Qwen UNKNOWN, веса сейчас не скачиваются. ML использует только данные кейса без pretrained-весов. Бюджет 600 ₽ не включён в рабочее планирование.
