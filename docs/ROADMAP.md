# Маршрут полноценного проекта

Основные требования — [ТЗ](TECHNICAL_SPEC.md), точный порядок 50 малых заданий — [WORK_BLOCKS](WORK_BLOCKS.md). Цели: AutoResearch, универсальность/переносимость, качество RMSE/F1 и корректный ответ до 3 часов. Mini — историческая проверка, а не текущий продукт.

| Этап | Что делаем | Фактическое состояние |
| --- | --- | --- |
| H00 | Источники, ТЗ, доказательства и минимальная среда | Документы; отдельный minimal-WSL PASS |
| H01 | Обзор источников, математика, harness, план сравнения | Проектирование готово; эксперименты NOT_RUN |
| H02 | Пакеты, entrypoint, TaskContract, Docker/profile | Только stdlib-WSL существует; остальное NOT_RUN |
| H03 | Профиль, преобразования, метрики, split и CSV | NOT_RUN полного агента |
| H04 | CPU-модели обеих задач и разбор ошибок | NOT_RUN |
| H05 | OS-worker, срок, ресурсы и восстановление | NOT_RUN; возможности образа неизвестны |
| H06 | Qwen/replay/live-safe-tool/failures | API_WAIT_LOCAL; mini не заменяет tools |
| H07 | Настоящий AutoResearch и вариант ролей P1 | NOT_RUN |
| H08 | Новые схемы, метрики, текст и холодные запуски | NOT_RUN |
| H09 | A–E, C/D, freeze/refit/outer | Только план |
| H10 | ZIP, чистый контейнер, длительный run | NOT_RUN полного агента |
| H11 | Сравнение замороженных версий команды | План; другие версии и согласие ещё не получены |
| H12 | Preflight, отправка и финальные доказательства | NOT_RUN полного агента; mini-наблюдения отдельно |

Ближайший кодовый шаг после ТЗ — H02.1. H06.1 возможен без ключа; H06.2 после ключа проверяет безопасный инструмент отдельно от ML. AutoResearch H07 требует H04+H05+H06. Generated code не запускается до OS-проверки. Полные 24/30/72/90 часовые серии — расчёты объёма будущих работ, не обещанный срок проекта.

Первые три дня участники делают независимые версии; этот чат — версия Владимира/Codex. Сначала регрессия, затем классификация через общий контракт. Три роли одной Qwen предусмотрены; польза независимых контекстов определяется сравнением, а не их числом.

WSL на E: уже создана. WSL24GiB/Docker20GiB/8CPU — ещё план; платформа задаёт 8CPU/32GB и Python3.12. GPU локально может использоваться в необязательном отдельном эксперименте, CPU-приёмка остаётся обязательной.

Выбран provided Qwen API. Другие модели через собственные API запрещены; допустимость локальной той же Qwen UNKNOWN, веса сейчас не скачиваются. ML обучается только на данных кейса без pretrained-весов. Интернет-источники обосновывают дизайн. Бюджет 600₽ не включён в рабочее планирование.
