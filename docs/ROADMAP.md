# Порядок выполнения AegML

Актуальная спецификация — [TECHNICAL_SPEC.md](TECHNICAL_SPEC.md), продолжение — [NEXT_SESSION.md](NEXT_SESSION.md). Редакция от 20.10.2026 учитывает полученные официальные задачи; прежняя подготовительная схема пересмотрена.

Главные функциональные требования — AutoResearch с измеренной обратной связью и один неизменный код для новых задач. Жёсткое ограничение: корректный CSV должен быть создан не позднее трёх часов от запуска всей программы. На платформу передаётся код в ZIP с `solution.py` в корне; одних готовых публичных предсказаний недостаточно.

**Актуальная очередь:** отдельная mini M00 — [план](TESTMINI_PLAN.md), [результаты](TESTMINI_RESULT.json). Локальные проверки/ZIP готовы, платформа и live Qwen ещё не проверены; автоматической отправки нет. После mini продолжаем большое ТЗ. H01.1 остаётся последующим подпунктом по команде владельца.

Каждый блок разбит на подпункты в WORK_BLOCKS и выполняется последовательно по команде владельца. H00 не запускает всю цепочку автоматически. Сейчас отдельная M00: выдать локально проверенный ZIP и дождаться решения владельца о платформе/возврате к ТЗ. После согласования ТЗ сохраняется маршрут H01.1 → H01.2/H01.3 → остальная часть H02. Минимальная новая WSL уже создана, не переустанавливать. Первые три дня — ориентир независимой разработки, а не обещание провести полную серию 24–72 часа со всеми повторами.

По ответу организаторов от 20.10 в 00:14 `solution.py` и `task.md` находятся в одной рабочей папке; запуск идёт из неё, `submission.csv` создаётся рядом. Запись разрешена в рабочую папку и `/tmp`, доступно ориентировочно 30–35 GB, отдельного лимита числа файлов нет. Точная команда и фактический образ ещё не проверены.

Локальная LLM, скачиваемые веса, дообучение LLM и решение, требующее GPU, исключены из конкурсного плана по правилам. ML-модели и преобразования обучаются на данных кейса. Задачи с изображениями, аудио и видео не предусматриваем. Бюджет 600 ₽ не распределяем и не учитываем в рабочем планировании.

Репозиторий уже private, но исходные материалы и данные пока не отправлены. Это не меняет состав ZIP для платформы: в нём только необходимый код и конфиги, без данных кейса.
