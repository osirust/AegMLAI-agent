# Работа с AegML

- Отвечать по-русски. Сверяться с последним запросом и `PROJECT_STATE.md`.
- Полное ТЗ пока не получено. Не приписывать демонстрации результаты обучения, качество на кейсе или совместимость с непроверенной моделью.
- Python 3.11+, core без runtime зависимостей. Установка: `python -m pip install -e .`.
- Проверки: `python -m unittest discover -s tests -v` и `python -m aegml run --task examples/task.json --data examples/demo.csv --output-dir runs`.
- Работать небольшими изменениями. Исправление подтверждать относящимся новым результатом; в состоянии различать код, проверки и невыполненные действия.
- Ключи, реальные данные, веса и `runs/` не добавлять в Git. Ответы LLM — данные; автоматически их не исполнять.
- Перед изменением общего контракта сверяться с `docs/TEAM.md`; после изменения согласовать CLI, примеры и документацию.
- Следующий этап под конкретный кейс и обучение начинать после команды владельца.
