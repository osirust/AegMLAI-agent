# AegML

ML-агент для задач регрессии и классификации на табличных данных. Проект подготовили для участия в треке AutoML хакатона «Альфа-Будущее 2026».

На вход агент получает описание задачи и CSV-файлы. Он проверяет данные, готовит признаки, обучает модель и записывает прогнозы в `submission.csv`.

## Что делает агент

- Читает условие задачи, словарь признаков и формат ответа.
- Проверяет целевой столбец, типы данных и соответствие входных файлов.
- Обрабатывает числовые и категориальные признаки, текст и пропуски.
- Разделяет данные для обучения и валидации, включая временное разбиение.
- Обучает базовую модель CatBoost и оценивает её по метрике задачи.
- Сохраняет прогнозы и отчёт о запуске.

Преобразования признаков обучаются на тренировочной части. Контрольные данные используются для оценки результата.

## Над чем работали

Во время хакатона мы сравнивали CatBoost, LightGBM, XGBoost, ExtraTrees и ансамбли, разбирали ошибки классификации и регрессии, проверяли новые признаки.

Отдельное направление — исследовательский цикл с Qwen: предложить изменение, провести эксперимент и сравнить результат с предыдущим вариантом. В репозитории сохранены технические заметки по этому подходу. Основной CLI в опубликованной версии запускает базовую модель.

## Запуск

Нужны Python 3.12 и зависимости из [requirements.txt](requirements.txt).

Команда для среды конкурса:

```bash
python3 solution.py task.md
```

Запуск выполняется из каталога задачи. Пути к данным задаются в `task.md`; готовый `submission.csv` появляется в рабочем каталоге.

[Инструкция для локального запуска](docs/READ_FIRST.md).

## Устройство репозитория

| Файлы | Назначение |
| --- | --- |
| `solution.py` | Точка входа |
| `aegml_input.py`, `aegml_contracts.py` | Чтение условия и проверка входных данных |
| `aegml_profile.py`, `aegml_preprocessing.py` | Анализ таблиц и подготовка признаков |
| `aegml_baseline.py`, `aegml_estimators.py` | Обучение базовой модели |
| `aegml_metrics.py`, `aegml_validation.py` | Метрики и валидация |
| `aegml_submission.py` | Проверка и сохранение прогнозов |
| `tests/` | Проверки компонентов |
| `docs/` | Технические заметки и материалы разработки |

Данные соревнования, API-ключи и обученные веса хранятся отдельно от репозитория.
