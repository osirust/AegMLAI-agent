## Что действительно сделано

- `testmini/solution.py`: stdlib, чтение task/CSV/словаря, target/id по ролям, mean для регрессии и majority для классификации; признаки не используются. Рядом с task создаются submission.csv и mini_diagnostics.json, stdout JSONL. Результат проверяется и заменяется атомарно.
- Optional API probe: один короткий Chat Completions запрос при всех OPENAI_API_KEY/OPENAI_BASE_URL/OPENAI_MODEL; при отсутствии настроек явный skipped. Ошибки API отмечаются отдельно, CSV сохраняется. Ответ модели не исполняется и не влияет на прогноз.
- ZIP `dist/testmini.zip`, только solution.py в корне. Размер и точные SHA — TESTMINI_RESULT. Датасеты, ключи, пакеты и веса в ZIP отсутствуют.
- Проверено в отдельной WSL AegML-Hackathon, Python 3.12.3: regression 22 449 строк / 3,0592 с; classification 41 166 / 1,7288 с. Проверены схема, порядок ID, конечность/метки, renamed target/id и ошибочный порядок sample с сохранением последнего CSV. 12 исходных файлов не изменились.
- API проверен только локальным HTTP stub: корректный ответ, ошибки/redirect/оборванный и некорректный ответ; ключей организаторов и расходов не было. Отдельная квитанция сохраняет число и scope тестов. Это не live Qwen.
